PasswordMan 绿色便携版
======================

使用说明：
1. 直接双击 password-man.exe 运行程序
2. 数据库文件 pwd.db 会自动创建在 exe 同级目录下
3. 可以点击程序中的 📂 按钮打开数据库所在目录

系统要求：
- Windows 10/11
- WebView2 运行时（Windows 11自带，Windows 10如未安装请访问：
  https://developer.microsoft.com/microsoft-edge/webview2/）

特点：
✓ 真正的便携版，数据库和exe在一起
✓ 无需安装，直接运行
✓ 删除文件夹即可完全卸载
✓ 可复制到U盘随身携带
✓ 数据随程序走，换电脑也能用

注意：
如果放在 Program Files 目录，可能因权限问题无法创建数据库
建议放在用户目录（如桌面、文档）或其他有写入权限的位置
